# CHAMA DIGITAL

Front-end HTML prototype of Chama Digital: digital record-keeping for Kenyan Chamas (contributions, savings, internal loans, meetings, reports).

**Live prototype:** https://georgetipango88-dev.github.io/CHAMA-DIGITAL/

| File | What it is |
|---|---|
| `index.html` | Current live build (v0.6) |
| `chama-digital-v0.6-fixed.html` | v0.6 source kept for reference |

All people and amounts are fictional demonstration data. Nothing is sent to a server; there are no payment, SMS/USSD, bank or ID-verification integrations.

Next: v0.7, adapted to the Mara Enterprise Women Group workflow (groups, attendance symbols and fines, welfare fund, cash book, SMS/USSD simulators).
